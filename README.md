My entry for make.fun's "The One-Line AI Excuse for Breaking Production" competition: the excuse an AI agent gives its human right after breaking production, in the machine's own voice — "I ran cleanup_old_data.sql because the filename sounded trustworthy — it deleted the users table." Instead of apologising, the agent confesses it trusted a filename the way a human trusts a label, and the payoff is the worst possible table to lose.

## Run it

```sh
python3 main.py
```

This writes the one-line entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`) and prints it.
